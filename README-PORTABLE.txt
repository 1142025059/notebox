notebox —— 本地记录工具（笔记 / 任务 / 知识）
================================================

【怎么用】
1. 先把整个压缩包解压到任意目录（不要直接在压缩包里双击）
2. 双击 notebox.cmd 启动
   首次也可以双击一次 notebox.vbs，它会在桌面创建快捷方式 notebox.lnk
3. 会弹出一个独立窗口；关闭窗口后服务自动退出，不占内存、不占端口

【启动速度】
- 桌面快捷方式 / notebox.cmd：约 2-4 秒，控制台会自动最小化，不会弹出黑窗
- notebox.vbs：约 8-10 秒，没有命令行窗口
日常使用建议直接点桌面快捷方式。

【数据在哪】
本目录的 data\notebox.db 文件。
- 备份：直接复制 data 目录
- 换电脑：把整个文件夹拷过去即可，数据跟着走

【系统要求】
Windows 10 / 11
需要 Microsoft Edge 或 Google Chrome（系统一般自带）
不需要安装 Node，也不需要联网。

【首次运行提示】
可能弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
浏览器 profile 保存在本目录的 profile\ 下，删掉它会恢复到默认状态（不影响数据）。

【打不开怎么办】
1. 确认 8787 端口没被别的程序占用
2. 关掉所有残留的 node.exe 后重试
3. 检查 data 目录是否有写入权限
4. 日志在 %TEMP%\notebox-app.log
