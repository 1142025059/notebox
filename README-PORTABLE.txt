notebox —— 本地记录工具（笔记 / 任务 / 知识）
================================================

【怎么用】
双击本目录下的 notebox.vbs。
会弹出一个独立窗口，关闭窗口后服务自动退出，不占内存。

【数据在哪】
本目录的 data\notebox.db 文件。
- 备份：直接复制 data 目录
- 换电脑：把整个文件夹拷过去即可，数据跟着走

【系统要求】
Windows 10 / 11
需要 Microsoft Edge 或 Google Chrome（系统一般自带）

【首次运行提示】
可能弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。

【打不开怎么办】
1. 确认 8787 端口没被别的程序占用
2. 关掉后重试
3. 检查 data 目录是否有写入权限

【说明】
这是便携版，不需要安装 Node，也不需要联网。
